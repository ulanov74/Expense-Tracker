# Expense Tracker

**Автор:** Ульянов Михаил


## Описание программы
Это простое GUI-приложение для отслеживания личных расходов. Вы можете добавлять расходы с указанием суммы, категории и даты, фильтровать по этим параметрам, а также видеть общую сумму расходов за выбранный период.

## Как использовать
1. Запустите файл `expense_tracker.py`.
2. Введите сумму (число > 0), категорию, дату в формате ГГГГ-ММ-ДД.
3. Нажмите «Добавить расход» — расход добавится в таблицу.
4. Для фильтрации введите категорию и/или дату, нажмите «Применить фильтр».
5. Для сброса фильтров — нажмите «Сбросить фильтр».

Все данные сохраняются в файле `expenses.json`.

## Примеры тестов
- Добавление расхода: сумма 150.50, категория "Еда", дата "2024-05-01".
- Фильтр по категории: "Еда".
- Фильтр по дате: "2024-05-01".
- Общая сумма отображается автоматически.
